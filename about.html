About the finder

A discovery tool built around source checking, transparent dates and student usability.

The purpose is simple: reduce the number of separate websites a student, parent, teacher or guidance counsellor has to search to discover worthwhile academic opportunities.

What is included

The public finder covers structured opportunities relevant to secondary-school students in Ireland, including academic competitions, TY and enrichment programmes, summer opportunities, courses, scholarships, bursaries, grants and other funding routes. Records are grouped so users can search everything together or focus on one opportunity type.

How records are researched

Provider-first sourcing

Official organiser, university, programme or scholarship pages are preferred. Where available, current-cycle pages, eligibility evidence and cost/award evidence are stored separately.

Verification metadata

Records can carry last-verified dates, eligibility checks, cost checks and confidence information so users can see how recently a record was reviewed.

Current-cycle caution

A recurring opportunity is not automatically treated as open. The finder distinguishes current availability, future/expected cycles, closed recurring opportunities and records that need review.

No invented exact dates

If the organiser has not published the next exact date, the exact-date calendar does not manufacture one. Expected/provisional information is labelled separately.

How to read date confidence

Confirmed

An exact date for the relevant cycle is published in the maintained record.

Expected / provisional

The opportunity is recurring or partially announced, but not every next-cycle date is fully confirmed. Re-check before relying on it.

Date recorded

A useful dated milestone exists in the record but does not carry a stronger confirmation label.

What the finder does not replace

The finder is not the application portal and is not the final authority on eligibility. Providers can alter deadlines, prices, award values, selection rules or programme details after a record is checked. The official provider page should always be the final step before an application, payment or travel decision.

Student accounts, saves and feedback

No account required

The current public frontend does not require students to create an account to search the database.

Saved opportunities stay in the browser

The saved list uses browser storage on the device being used. Clearing browser/site data may remove that list.

Anonymous correction workflow

The opportunity detail view provides a problem-report form designed without a name or email field. It can flag broken links, changed dates, eligibility issues, discontinued opportunities, missing information or suggestions.

Public/private separation

The live web payload is deliberately separated from maintenance/admin fields. Release regression checks verify public IDs and test for private-field leakage.

Release quality

The production release includes automated/browser-side checks for dataset size, anchor records, duplicate public IDs, rich-detail fields, calendar ordering, direct links, feedback wiring and the Related API. The maintained spreadsheet also contains regression, duplicate-review and web data-quality surfaces used during release verification.

Corrections and omissions

No large opportunity database is permanently complete. New schemes appear, old schemes stop, providers rename programmes and deadlines move. If a record looks wrong, use the report option inside the opportunity. If an opportunity is missing, the same reporting workflow can be used as a suggestion for review.

Important: Inclusion in the finder is not an endorsement of an organisation, programme, competition or scholarship. Users should consider suitability, safeguarding, travel, cost and application requirements independently.
