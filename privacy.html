Privacy

Privacy Policy

How the public finder and its private deployment automation handle data.

Public finder

The Irish Academic Opportunities Finder can be searched without creating an account. Saved opportunities are stored locally in the user’s browser. The public site does not ask students to sign in with Google.

Feedback

The opportunity correction form is designed to accept anonymous reports without requesting a name or email address. Reports may include the opportunity identifier, opportunity name, issue category, message, page URL and a randomly generated browser identifier used to support review and abuse prevention.

Google OAuth deployment automation

A separate private OAuth client named Irish Academic Opportunities Deployment is used only by the site maintainer to automate deployment of the existing Google Apps Script backend. It is not offered as a sign-in option to students or public finder users.

The OAuth client requests the Google Apps Script project and deployment management permissions required to read and update the maintained Apps Script project and its deployment configuration. The automation does not request Gmail, Contacts, Calendar or general Google Drive access.

How Google user data is used

Google authorization data is used solely to authenticate automated deployment operations for the maintainer’s Apps Script project. OAuth refresh credentials are stored as encrypted GitHub Actions repository secrets and are not committed to the public repository. Short-lived access tokens generated during a deployment workflow are used only for the Google Apps Script API calls required for that deployment.

Google user data obtained through these permissions is not sold, used for advertising, or shared with third parties for unrelated purposes.

Data retention and access

The deployment refresh credential remains stored in GitHub Actions Secrets until it is rotated, revoked or removed by the maintainer. Workflow execution records may contain operational metadata, but credentials are not intentionally written to logs. Access is limited to the repository automation and the maintainer’s authorized Google account.

Revoking access

The maintainer can revoke the OAuth grant through the Google Account security controls, remove or rotate the GitHub repository secret, disable the OAuth client, or remove the deployment automation at any time.

Source data and public/private separation

The public finder displays a curated subset of the maintained opportunities database. Private research, monitoring and administrative fields are deliberately excluded from the public API payload.

Changes

This policy may be updated when the finder or deployment architecture changes. The current version is published at this URL.
